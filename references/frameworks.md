# Frameworks

以下框架用于任务执行。历史经验型框架只作为假设，不应描述为平台当前算法。

## 1. Four-constraint positioning

方向同时检查：

**用户要看 × 我们能做 × 平台允许 × 市场可验证**

再加入自身资产：经历、成果、长期表达意愿和差异优势。

## 2. Positioning as experiment

**方向假设 → 小样本内容 → 用户反馈 → 商业意向 → 数据比较 → 定位收敛**

定位不是一次性决策。

## 3. Demand-to-topic

**关键词/评论/咨询 → 需求簇 → 用户意图 → 内容问题 → 选题**

避免只有关键词表，没有内容策略。

## 4. Content production chain

图文：

**选题 → 提纲 → 正文/图片脚本 → 视觉 → 发布 → 互动 → 复盘**

视频：

**选题 → 提纲 → 脚本 → 拍摄 → 剪辑 → 视觉包装 → 发布 → 互动 → 复盘**

## 5. Acquisition MVP

**曝光 → 意向 → 有效线索 → 成交**

只有链路形成真实商业结果，才算进入可放大阶段。

## 6. Business model

可用通用业务链路检查：

**产品/服务 → 流量 → 销售 → 交付**

如果销售或交付有问题，仅增加流量不会解决根因。

## 7. Test funnel heuristic

付费/素材可采用：

**多个种子 → 保留较优一部分 → 聚焦头部 → 继续验证**

“5 个以上种子、前约 30%、再看头部约 10%”可作为一种启发式配置，但不是规则。

## 8. A/B testing

**假设 → 变量 → 控制条件 → 结果指标 → 判断 → 下一轮**

一次减少变量数量，提高可解释性。

## 9. Unit economics

常用：

- CAC：获得一个客户的成本
- LTV：客户生命周期价值
- ROI：投入相对产出的回报

付费和规模化最终必须回到单位经济。

## 10. Pareto + long tail

- 二八法则：优先识别少数高贡献内容/关键词/客户类型。
- 长尾效应：大量低频但高匹配需求可能形成稳定搜索和获客资产。

两者结合：既维护头部主题，也持续积累高意向长尾。
