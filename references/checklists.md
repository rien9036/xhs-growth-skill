# Checklists

## New project checklist

- [ ] 产品/服务是什么
- [ ] 目标客户是谁
- [ ] 客单价与毛利
- [ ] 地域/交付约束
- [ ] 目标是曝光、线索还是成交
- [ ] 2–4 个方向假设
- [ ] 当前平台是否允许该业务/表达
- [ ] 搜索需求证据
- [ ] 近期内容样本
- [ ] 小样本测试计划
- [ ] 数据记录方式

## Positioning checklist

- [ ] 用户愿意看
- [ ] 自己能持续做
- [ ] 与业务直接相关
- [ ] 平台当前允许
- [ ] 有搜索/评论/咨询证据
- [ ] 账号一句话价值清楚
- [ ] 与替代账号有可解释差异
- [ ] 不依赖虚假身份或夸张承诺

## Note checklist

- [ ] 一个明确目标用户
- [ ] 一个核心需求
- [ ] 一个核心结论
- [ ] 封面一眼可懂
- [ ] 标题具体
- [ ] 关键词自然
- [ ] 前部快速交付价值
- [ ] 有步骤/证据/案例
- [ ] CTA 符合当前规则
- [ ] 无虚假数据
- [ ] 无抄袭/搬运
- [ ] 已定义复盘指标

## Funnel checklist

- [ ] 曝光
- [ ] 点击/阅读
- [ ] 深度互动
- [ ] 商业意向
- [ ] 有效线索
- [ ] 成交
- [ ] 毛利
- [ ] CAC
- [ ] LTV
- [ ] 最大掉点已定位

## Paid growth checklist

- [ ] 已有自然验证
- [ ] 有明确转化事件
- [ ] 可接受 CAC 已知
- [ ] 有多个素材
- [ ] 变量控制
- [ ] 小预算起步
- [ ] 止损条件
- [ ] 放大条件
- [ ] 当前广告功能已核验

## Scaling checklist

- [ ] 单元已重复验证
- [ ] 内容 SOP 已文档化
- [ ] 线索承接稳定
- [ ] 销售可承接
- [ ] 交付可承接
- [ ] 单位经济健康
- [ ] 新账号/新内容有独立价值
- [ ] 不用于规避平台处罚
- [ ] 已设置质量和停止条件
