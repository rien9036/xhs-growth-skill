# Case Patterns

案例只用于识别模式，不提供收入保证，也不复制特定案例原文。

## Pattern 1 — Narrow local category

适用于：
- 地域明确
- 市场较小
- 单日内容供给不高
- 客户搜索意图强

打法：
1. 地域 + 品类关键词
2. 高频回答长尾问题
3. 覆盖多个真实用户场景
4. 通过搜索与本地内容入口获取精准曝光
5. 用咨询/预约等当前允许工具承接

重点不是总粉丝量，而是目标地域内的搜索覆盖和有效咨询。

## Pattern 2 — High-ticket local service

适用于：
- 家装
- 摄影
- 咨询
- 教育
- 其他高决策成本服务

内容资产：
- 案例
- 预算/价格
- 流程
- 避坑
- 对比
- 交付结果
- 地域服务能力

漏斗重点：
精准搜索 → 信任 → 咨询 → 方案 → 成交。

## Pattern 3 — Education / knowledge service

需求通常高度结构化：
- 考试节点
- 学习阶段
- 资料
- 方法
- 选择机构
- 价格
- 成绩/结果焦虑

适合建立“时间节点 × 用户阶段 × 问题”的选题矩阵。

免费资料可能带来大量低质量线索，因此需结合资格筛选和真实交付价值。

## Pattern 4 — Personal expert IP

不要只展示身份。

建立：
- 专业问题解决能力
- 经历和观点
- 可信证据
- 稳定栏目
- 用户案例
- 产品/服务承接

IP 内容和获客内容需要有重叠区域，否则容易有粉丝无业务。

## Pattern 5 — E-commerce

重点观察：
- 用户搜索需求
- 产品视觉
- 比较/测评
- 场景
- 购买疑问
- 站内商品/店铺/直播等当前能力
- 毛利和投放成本

平台电商功能变化快，所有店铺类型、保证金、佣金和入口需核验当前规则。
