# Paid Growth

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 要投放、测试素材、控制 CAC/ROI 或放大有效内容

**Scope:** 素材测试、预算、CAC/ROI 与付费放大

**Method intent:** 在自然获客已有证据后设计小红书付费增长测试，包括素材筛选、预算、受众、关键词、CAC/ROI 与止损规则。

## Goal

付费的作用是**验证和放大有效模式**，不是用预算掩盖定位、内容或产品问题。

## Preconditions

至少满足大部分条件再考虑放大：

- 目标客户明确
- 产品/服务可交付
- 已有自然内容表现证据
- 有明确转化事件
- 能记录有效线索和成交
- 知道可接受 CAC
- 有止损预算
- 当前广告账户/资质符合平台规则

## Procedure

### 1. Define the objective
只选一个主目标：
- 内容阅读/互动
- 粉丝增长
- 搜索占位
- 线索
- 商品成交
- 直播等

具体可选目标必须按当前广告平台实际功能核验。

### 2. Build a seed set
选择多个素材/选题进入小预算测试，避免把全部预算押在一篇内容。

### 3. Control variables
一次尽量只测试一个主要变量：
- 素材
- 封面/标题
- 关键词
- 人群
- 出价
- 落地承接

### 4. Use a funnel selection heuristic
可以用“多素材 → 选出前一部分 → 再选头部”的漏斗思路。

例如：
- 第一阶段至少准备多个种子素材
- 第二阶段保留表现前约 30%
- 第三阶段集中验证头部约 10%

这些比例只作为测试启发，不是平台规则，也不必机械执行。

### 5. Evaluate business metrics
优先计算：
- CPM / CPC（若适用）
- 单线索成本
- 有效线索率
- 成交率
- CAC
- 客单价
- 毛利
- LTV
- ROI

### 6. Scale or stop
只有当增量预算没有显著破坏 CAC/ROI 时才逐步加预算。

## Outputs

- 投放目标
- 素材测试矩阵
- 预算分层
- 核心指标
- 止损条件
- 放大条件
- 复盘模板
- 当前平台功能核验清单

## Avoid

- 因为“别人 ROI 很高”就假设自己也能复制
- 把历史广告产品名称、白名单、门槛当作当前事实
- 只看互动成本，不看有效线索或成交
- 在产品/销售端尚未跑通时无限加预算
