# Organic Distribution & SEO

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 有内容但搜索/推荐/互动弱，或要诊断自然流量

**Scope:** 搜索、推荐、点击、互动与自然流量诊断

**Method intent:** 诊断小红书内容的搜索、推荐、收录、点击、阅读和互动问题，并提出自然流量优化方案。

## Goal

把“没流量”拆成可诊断的问题，而不是用未经验证的算法传说解释一切。

## Distribution layers

至少区分：

1. 内容是否正常发布/可见
2. 是否能被搜索或相关主题发现
3. 是否得到推荐曝光
4. 是否有人点击/阅读
5. 是否形成深度阅读
6. 是否形成收藏、评论、分享、搜索等深度行为
7. 是否出现商业意向

## Inputs

- 笔记链接/内容
- 发布时间
- 曝光或观看量
- 流量来源
- 点击/阅读指标（如可得）
- 互动数据
- 搜索词
- 历史同类笔记
- 账号近期状态

## SEO procedure

### 1. Check demand match
确认内容回答的是一个真实存在的需求。

### 2. Check semantic signals
封面、标题、正文、话题应能清楚表达核心主题和关键词。

### 3. Check search discoverability
用当前平台允许的方式检查：
- 标题/关键词是否可搜索
- 搜索流量来源是否出现
- 长尾词是否匹配
- 内容是否与目标搜索意图一致

### 4. Check clickability
曝光有但阅读弱时，重点检查：
- 封面是否一眼可懂
- 标题是否具体
- 是否与目标人群相关
- 是否承诺过度导致信任下降

### 5. Check depth
阅读有但互动/停留弱时，检查：
- 前部信息价值
- 结构
- 信息密度
- 可收藏性
- 用户参与点

### 6. Check intent
互动高但无客户时，检查内容是否偏娱乐/泛人群，离产品需求太远。

## Diagnostic rules

- 极低数据可能来自内容问题、账号状态、品类竞争、平台审核或暂时分发差异；不能仅凭一个阈值断定“限流”。
- 搜索流量高说明内容可能具备长期需求承接价值，但仍要看意向和转化。
- 推荐流量高不等于精准获客。
- 点赞只是一个互动信号，不应单独作为质量判断。

## Outputs

- 当前掉点
- 可能原因（按证据强弱排序）
- 最小修改方案
- 下一轮测试变量
- 需要当前平台核验的事项

## Guardrail

任何“权重公式”“推荐池阈值”“固定时长标准”若无当前官方依据，只能作为历史经验假设，不能描述成确定算法。
