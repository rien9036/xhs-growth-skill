# Analytics & Experimentation

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 要分析数据、竞品或设计增长实验

**Scope:** 数据诊断、A/B 测试与增长实验

**Method intent:** 用笔记、账号、受众、竞品和行业数据诊断增长瓶颈，并设计变量可控的 A/B 测试与增长实验。

## Goal

把“运营感觉”变成可验证假设。

## Analysis levels

### Note level
关注：
- 曝光/观看
- 流量来源
- 阅读/播放深度
- 收藏
- 评论
- 分享
- 搜索行为
- 意向信号
- 线索/成交

### Account level
关注：
- 发布频率
- 内容类型分布
- 推荐/搜索来源
- 粉丝增长
- 用户画像
- 高意向内容占比
- 线索与成交趋势

### Competitor level
关注：
- 最近有效主题
- 内容形式
- 目标人群
- 评论区需求
- 商业承接
- 更新频率

### Industry level
关注：
- 搜索趋势
- 热门需求
- 季节变化
- 新兴品类
- 竞争强度
- 广告价格/供给（如可得）

## Funnel diagnosis

依次问：

1. 是否有曝光？
2. 曝光是否精准？
3. 是否有人点击/阅读？
4. 是否形成深度互动？
5. 是否出现商业意向？
6. 是否形成有效线索？
7. 是否成交？
8. 成交后单位经济是否健康？

先找最靠前的异常层。

## Experiment design

每个实验写清：

- 假设
- 主要变量
- 控制变量
- 样本范围
- 观察周期
- 成功指标
- 失败条件
- 结果
- 下一步

例：

**假设：地域 + 痛点型封面比泛行业封面更能带来本地咨询。**

主要变量只有封面/标题定位；正文、发布时间、内容主题尽量保持相似。

## Business metrics

当进入商业化阶段，补充：

- 有效线索率
- 成交率
- CAC
- 客单价
- 毛利
- LTV
- ROI

## Outputs

- 数据摘要
- 漏斗掉点
- 证据强度
- 3 个以内优先假设
- 下一轮实验
- 成功/停止条件

## Guardrail

不要用单篇笔记或很小样本推出平台“算法真相”。历史经验阈值只能作为排查起点。
