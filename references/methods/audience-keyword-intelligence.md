# Audience & Keyword Intelligence

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 不知道目标用户在搜什么、关心什么、如何找长尾需求

**Scope:** 目标用户、需求信号、关键词与长尾需求

**Method intent:** 从搜索、评论、咨询、行业趋势和竞品中提取用户需求、关键词和长尾机会，并把需求转换成选题。

## Goal

把关键词从“SEO 词表”升级为“用户需求地图”。

关键词的价值不是出现次数，而是它揭示了：
- 用户是谁
- 正在解决什么问题
- 处于什么决策阶段
- 是否有购买意向
- 竞争是否激烈
- 内容应该回答什么

## Inputs

- 产品/服务
- 目标用户
- 地域
- 核心品类词
- 已有客户咨询
- 竞品或样本笔记
- 当前可访问的搜索/行业数据

## Sources to inspect

优先使用当前可获得的数据：

1. 平台搜索框的联想词
2. 搜索结果页的相关词/大家都在搜
3. 评论区的真实问题
4. 自己的私信、客服、销售记录
5. 官方行业趋势/商业报告
6. 广告关键词规划工具（如当前仍提供）
7. 合法第三方数据工具
8. 竞品高意向评论
9. 季节性与行业事件

## Demand taxonomy

将需求按意图分类：

- **认知型**：是什么、为什么
- **比较型**：哪个好、区别、推荐
- **解决方案型**：怎么做、流程、方案
- **风险型**：避坑、失败、注意事项
- **价格型**：多少钱、预算、费用
- **交易型**：怎么买、哪里买、是否可预约
- **本地型**：城市/区域 + 服务
- **时效型**：今年、近期、政策、季节、考试/活动节点

## Procedure

### 1. Seed keywords
从业务定义提取 5–20 个核心种子词。

### 2. Expand
每个种子词扩展：
- 人群
- 地域
- 场景
- 痛点
- 价格
- 产品类型
- 结果
- 对比对象
- 时间节点

### 3. Mine comments
重点提取用户自己的语言，不改写成行业术语后再丢失原始意图。

### 4. Score
每个关键词至少评价：
- 需求强度
- 商业意图
- 内容竞争
- 与产品匹配度
- 时效性
- 可持续性

不强制虚构精确分数；数据不足时用高/中/低即可。

### 5. Cluster
把相似词聚为需求簇，避免得到一张几百个词但不可执行的表。

### 6. Convert to topics
一条需求簇至少生成：
- 解释型选题
- 对比型选题
- 清单型选题
- 案例型选题
- 决策型选题

### 7. Place keywords naturally
优先放在：
- 封面核心信息
- 标题
- 正文关键句
- 相关话题/标签

不堆砌，不破坏自然表达。

## Outputs

- 种子关键词
- 关键词簇
- 用户意图
- 商业意图
- 长尾机会
- 高优先级选题
- 后续应继续收集的数据

## Key rule

**高搜索量 ≠ 高获客价值。**

对商业账号而言，更关注“需求明确、产品匹配、用户接近决策”的词。
