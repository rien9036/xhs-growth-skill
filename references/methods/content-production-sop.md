# Content Production SOP

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 要建立选题库、内容 SOP 或提高内容生产效率

**Scope:** 选题、标题、封面、正文与内容生产 SOP

**Method intent:** 将小红书内容生产标准化为选题、提纲、脚本/正文、视觉、发布、互动和复盘流程，并建立可持续更新的内容资产库。

## Goal

让内容从“靠灵感写一篇”变成“可重复生产、可测试、可复盘的内容系统”。

## Production chains

图文：

**选题 → 提纲 → 正文/图片脚本 → 封面与标题 → 发布 → 互动 → 复盘**

视频：

**选题 → 提纲 → 脚本 → 拍摄 → 剪辑 → 封面与标题 → 发布 → 互动 → 复盘**

## Inputs

- 定位
- 目标用户
- 关键词/需求地图
- 产品与转化目标
- 历史有效内容
- 可用素材
- 品牌/个人表达风格

## Procedure

### 1. Select a topic
优先级：
1. 已验证的真实用户需求
2. 最近出现的高意向问题
3. 自己历史有效主题
4. 同类市场近期有效主题
5. 季节/行业事件
6. 新假设

不要把“模仿”理解成复制文字或视觉。只借鉴需求、结构、信息组织和问题 framing，重新生产原创内容。

### 2. Write the outline
先明确：
- 目标用户
- 一个核心问题
- 一个核心结论
- 3–5 个支撑点
- 希望用户下一步做什么

### 3. Produce the body
要求：
- 前部快速交付价值
- 用用户语言而不是公司内部术语
- 信息密度与可读性平衡
- 证据、案例、步骤与限制条件清楚
- 不夸大结果

### 4. Design cover & title
封面负责“第一眼理解”，标题负责“明确承诺/问题”。

测试方向包括：
- 结果
- 痛点
- 对比
- 清单
- 避坑
- 地域/人群
- 时间节点

### 5. Publish with semantic consistency
封面、标题、正文和话题围绕同一需求，不为关键词而关键词。

### 6. Interact
回复真实评论，继续挖掘问题，并把评论区变成下一轮选题输入。

不制造虚假评论或虚构排队效应。

### 7. Review
记录：
- 主题
- 目标人群
- 封面模式
- 标题模式
- 关键词
- 发布时间
- 曝光/阅读
- 深度互动
- 意向信号
- 线索/成交
- 结论

### 8. Maintain a topic library
选题库建议记录：
- 选题
- 需求簇
- 来源证据
- 适用人群
- 表现数据
- 是否已使用
- 可衍生角度
- 更新日期

## AI workflow

AI 适合：
- 聚类需求
- 生成多个标题方向
- 把提纲扩展为初稿
- 做不同人群版本
- 对历史评论进行主题归纳
- 生成复盘摘要

AI 不应该：
- 抄写他人内容
- 伪造案例或数据
- 为规避查重做同义替换
- 编造平台规则

## Outputs

- 内容 brief
- 提纲
- 正文/脚本
- 封面信息
- 标题候选
- 关键词
- 发布检查
- 互动问题
- 复盘字段
