# Lead Conversion Funnel

> Internal method reference for `xhs-growth-skill`. This file is not an independent Skill.

**Use when:** 有曝光或互动但咨询、线索、成交不足

**Scope:** 意向识别、线索承接与成交漏斗

**Method intent:** 将小红书流量转换为真实商业意向、合规线索和成交，并诊断曝光到成交各层的掉点。

## Goal

建立：

**曝光 → 阅读 → 意向 → 有效线索 → 销售沟通 → 成交 → 复购/转介绍**

避免把“加联系方式数量”当作唯一目标。

## Inputs

- 产品/服务
- 客单价
- 决策周期
- 复购频率
- 目标客户
- 当前流量
- 评论/私信类型
- 官方可用的线索/店铺/私信工具
- 销售与交付能力

## Intent signals

优先关注真实表达：

- 价格/预算
- 购买方式
- 预约/档期
- 地域服务范围
- 产品规格
- 方案咨询
- 对比与选择
- 交付时间
- 是否适合自己

点赞、收藏可能有价值，但不等于购买意向。

## Offer / hook design

“钩子”应当是对用户有真实价值的承接物，例如：

- 核心产品
- 低门槛体验产品
- 诊断/评估
- 资料或工具
- 试听/试用
- 咨询
- 社群/活动（若平台规则和业务模式允许）

判断标准：
- 与最终产品高度相关
- 能筛选目标客户
- 用户愿意投入一定时间/行动
- 不靠虚假稀缺或欺骗
- 交付成本可控

## Procedure

### 1. Map the funnel
记录每一层：
曝光 → 意向互动 → 官方允许的咨询/留资 → 有效线索 → 成交。

### 2. Diagnose precision
如果曝光多、咨询少：
- 选题是否离产品太远
- 用户是否不是目标客户
- CTA 是否不明确
- 信任证据是否不足

### 3. Diagnose lead quality
如果线索多但质量低：
- 钩子是否太泛
- 是否吸引只求免费资料的人
- 是否缺少资格筛选
- 选题是否与购买阶段错位

### 4. Diagnose sales
如果线索质量高但成交弱：
- 产品与需求是否匹配
- 价格/方案是否清楚
- 信任和证据是否足够
- 响应是否及时
- 销售过程是否有结构
- 交付承诺是否可信

### 5. Choose a monetization model
根据业务特点判断更适合：
- 平台内商品/服务成交
- 官方线索收集/咨询
- 广告合作
- 直播
- 其他当前允许的商业功能

高频/低频、高客单/低客单、决策周期与复购率共同影响承接方式。

## Outputs

- 漏斗图
- 当前最大掉点
- 高意向用户定义
- 承接物/offer
- 资格筛选问题
- 销售前信息结构
- 转化指标
- 合规注意事项

## Compliance

不得提供隐藏联系方式、谐音、二维码拼接、绕审核私信话术等规避导流规则的方法。优先使用当前平台官方允许的商业与联系工具。
