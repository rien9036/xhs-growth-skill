# Capability Map

本仓库只有一个 Skill：`xhs-growth-skill`。下表均为该 Skill 的内部方法，不是独立 Skill。

| Internal method | Trigger | Scope | Reference |
|---|---|---|---|
| `account-launch-positioning` | 不知道从哪个方向开始、定位如何验证或账号怎么表达 | 方向测试、定位收敛、主页表达与视觉基线 | `references/methods/account-launch-positioning.md` |
| `audience-keyword-intelligence` | 不知道目标用户在搜什么、关心什么、如何找长尾需求 | 目标用户、需求信号、关键词与长尾需求 | `references/methods/audience-keyword-intelligence.md` |
| `content-production-sop` | 要建立选题库、内容 SOP 或提高内容生产效率 | 选题、标题、封面、正文与内容生产 SOP | `references/methods/content-production-sop.md` |
| `organic-distribution-seo` | 有内容但搜索/推荐/互动弱，或要诊断自然流量 | 搜索、推荐、点击、互动与自然流量诊断 | `references/methods/organic-distribution-seo.md` |
| `lead-conversion-funnel` | 有曝光或互动但咨询、线索、成交不足 | 意向识别、线索承接与成交漏斗 | `references/methods/lead-conversion-funnel.md` |
| `paid-growth` | 要投放、测试素材、控制 CAC/ROI 或放大有效内容 | 素材测试、预算、CAC/ROI 与付费放大 | `references/methods/paid-growth.md` |
| `matrix-scaling` | 单账号/单内容模型已经跑通，希望扩大规模 | 已验证模型的多账号与规模复制 | `references/methods/matrix-scaling.md` |
| `analytics-experimentation` | 要分析数据、竞品或设计增长实验 | 数据诊断、A/B 测试与增长实验 | `references/methods/analytics-experimentation.md` |
| `team-growth-ops` | 要搭团队、分工、培训、知识库或绩效机制 | 角色分工、SOP、培训、知识库与绩效 | `references/methods/team-growth-ops.md` |
